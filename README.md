# DESIGN AND ANALYSIS OF ALGORITHMS GROUP-17 – BSCS

## 1. Project Overview

This repository contains the **Design and Analysis of Algorithms (DAA) Group 17 project** developed by Bachelor of Science in Computer Science students.

The project focuses on implementing and demonstrating the assigned algorithmic concepts through C++ backend development and a user-friendly frontend interface. The team is organised into four backend modules, documentation, and frontend development.
